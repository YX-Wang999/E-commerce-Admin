# 备份恢复

> 面向：运维工程师

---

## 1. 备份范围

| 数据 | 路径/对象 | 优先级 |
|:---|:---|:---:|
| 数据库 | MySQL 或 `backend/db.sqlite3` | P0 |
| 媒体文件 | `backend/media/` | P0 |
| 环境配置 | `backend/.env` | P0 |
| 静态前端 | `*Dist/` | P1（可重建） |
| 代码 | Git 仓库 | P1（可重新部署） |

---

## 2. SQLite 开发/小型部署

### 2.1 备份

```bash
cd /var/www/admin/backend
cp db.sqlite3 "backups/db-$(date +%Y%m%d-%H%M).sqlite3"
tar -czf "backups/media-$(date +%Y%m%d).tar.gz" media/
```

### 2.2 恢复

```bash
systemctl stop ecommerce-backend
cp backups/db-YYYYMMDD.sqlite3 db.sqlite3
tar -xzf backups/media-YYYYMMDD.tar.gz -C .
systemctl start ecommerce-backend
```

---

## 3. MySQL 生产环境

### 3.1 全量备份（每日）

```bash
#!/bin/bash
# /opt/scripts/backup-mysql.sh
DATE=$(date +%Y%m%d)
BACKUP_DIR=/var/backups/ecommerce
mkdir -p "$BACKUP_DIR"

mysqldump -u"$DB_USER" -p"$DB_PASS" -h"$DB_HOST" "$DB_NAME" \
  | gzip > "$BACKUP_DIR/db-$DATE.sql.gz"

tar -czf "$BACKUP_DIR/media-$DATE.tar.gz" -C /var/www/admin/backend media/

# 保留 30 天
find "$BACKUP_DIR" -name "*.gz" -mtime +30 -delete
```

cron 示例：`0 2 * * * /opt/scripts/backup-mysql.sh`

### 3.2 恢复

```bash
systemctl stop ecommerce-backend
gunzip -c /var/backups/ecommerce/db-YYYYMMDD.sql.gz | mysql -u... -p... DBNAME
tar -xzf /var/backups/ecommerce/media-YYYYMMDD.tar.gz -C /var/www/admin/backend
python manage.py migrate   # 确保 schema 与代码一致
systemctl start ecommerce-backend
```

## 4. 恢复验证清单

- [ ] 后台可登录
- [ ] 商城可浏览商品
- [ ] 历史订单数据完整
- [ ] 商品图片可访问（media）
- [ ] WebSocket 通知正常

---

## 5. 灾难恢复 RTO/RPO 建议

| 指标 | 目标（可按企业调整） |
|:---|:---|
| RPO | ≤ 24 小时（日备） |
| RTO | ≤ 4 小时 |

关键业务可启用 MySQL 主从 + 增量 binlog 备份缩短 RPO。
