# 功能介绍

> 面向：老板、产品经理、业务方  
> 技术细节见 [架构设计](../02-开发人员专用/架构设计.md)

---

## 系统组成

一套代码、四个入口，覆盖 **平台监管 → 商家经营 → 买家购物** 全链路：

| 入口 | 谁在用 | 做什么 |
|:---|:---|:---|
| **商城** | 普通消费者 | 逛、买、付、收、评、售后 |
| **商家后台** | 店铺老板/员工 | 管货、发货、促销、客服 |
| **平台后台** | 公司内部运营 | 审核、监管、报表、配置 |
| **统一后台 API** | （用户无感） | 数据与安全中枢 |

---

## 一、商城（买家端）

| 模块 | 价值 |
|:---|:---|
| 账号注册登录 | 手机号 + 短信，支持找回密码 |
| 商品浏览 | 首页频道、分类、搜索、店铺页 |
| 购物车 | 登录前后购物车合并 |
| 下单支付 | 地址、优惠券、积分、国补资格 |
| 订单跟踪 | 状态流转、物流查询 |
| 积分会员 | 签到、等级、权益 |
| 促销活动 | 秒杀、拼团、领券、超级折扣 |
| 客服消息 | 在线沟通、系统通知 |
| 投诉建议 | 反馈与正式投诉工单 |

---

## 二、商家后台

| 模块 | 价值 |
|:---|:---|
| 工作台 | 今日经营数据一目了然 |
| 商品管理 | 上下架、库存（权限内） |
| 订单发货 | 待发货提醒、快递录入 |
| 促销报名 | 秒杀/拼团/优惠券（提交平台审核） |
| 客服 | 回复买家咨询 |
| 售后处理 | 退款/退货响应 |
| 店铺积分 | 本店积分规则与调整 |
| 标签营销 | 参与平台促销标签（如百亿补贴） |
| 申诉 | 对平台处罚进行申诉 |

---

## 三、平台后台

| 模块 | 价值 |
|:---|:---|
| 组织与权限 | 多角色、多部门、菜单级权限 |
| 商品与类目 | 全平台商品、品牌、类目治理 |
| 订单与售后 | 全平台订单、强制取消、售后仲裁 |
| 商户 lifecycle | 入驻审核、暂停、注销、变更审核 |
| 促销中枢 | 创建/审核秒杀、拼团、券、超级折扣 |
| 客服工作台 | 客户 + 商家双通道会话 |
| 投诉处理 | 三方投诉闭环 |
| 审核工作台 | 标签参与、店铺注销等统一待办 |
| 国补管理 | 政策、备案、订单上报 |
| 数据报表 | 销售、商品、客户、财务汇总 |
| 系统配置 | 公告、角色名称、参数 |

---

## 四、横切能力

| 能力 | 说明 |
|:---|:---|
| 实时通知 | 新订单、新消息、审核任务推送至导航红点 |
| 多语言 | 中/英/日（三端 UI） |
| 操作审计 | 关键后台操作留痕 |
| 短信 | 注册/找回（阿里云，可开发模式） |
