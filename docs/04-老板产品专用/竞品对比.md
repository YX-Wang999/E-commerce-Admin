# 竞品对比

> 面向：老板、产品、售前  
> 说明：以下为 **能力维度** 对比，不对指具体厂商；数据来自本项目 v1.0.0 已实现功能。

---

## 对比维度

| 维度 | 单体开源商城 | SaaS 电商 | **本系统 v1.0.0** |
|:---|:---|:---|:---|
| 平台 + 商家 + 买家三端 | 通常仅 C 端 | 有，但定制难 | ✅ 源码四项目一体 |
| 多租户店铺 | 插件或弱 | ✅ | ✅ Tenant 一等公民 |
| RBAC 多角色 | 简单管理员 | 按套餐 | ✅ 9 角色 + 动态菜单 |
| 促销（秒杀/拼团/券） | 部分 | ✅ | ✅ + 平台审核流 |
| 国补/政策类 | ❌ 少见 | 定制项目 | ✅ 独立模块 |
| 统一审核工作台 | ❌ | 分散 | ✅ approval 模块 |
| 双通道客服 | 单一 | 有 | ✅ 客户 + 商家 |
| 投诉闭环 | 简单留言 | 工单系统 | ✅ 三方流程 |
| 商家店铺积分 | ❌ | 部分 | ✅ seller_points |
| 店铺评分/注销 | ❌ | 部分 | ✅ 独立模块 |
| 源码可控 / 私有化 | ✅ | ❌ | ✅ |
| 上线运维成本 | 低~中 | 低 | 中（需自建，见 deploy/） |

---

## 适用场景

| 场景 | 建议 |
|:---|:---|
| 个人小店、只要一个网店 | 轻量 SaaS 可能更快 |
| **区域平台、多商户入驻** | ✅ 本系统匹配 |
| **需要国补、标签、强监管** | ✅ 本系统匹配 |
| **数据必须私有化部署** | ✅ 本系统匹配 |
| 快速验证 MVP、零运维 | 可考虑 SaaS，后期迁移 |

---

## 差异化总结（一句话）

**「可私有化部署的多租户电商中台」** — 兼顾买家体验、商家自助与平台强管控，而不是单纯的商城模板。
