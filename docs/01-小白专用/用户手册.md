## 1. 账号与安全

### 1.1 注册

- 路径：`/register`
- 需要：手机号 + 短信验证码 + 密码
- 短信场景：`register`（注册专用模板）

### 1.2 登录

- 路径：`/login`
- 支持：**手机号**、**昵称**、**邮箱** + 密码
- 登录后可使用购物车、订单、积分、客服等完整功能

### 1.3 找回密码

- 路径：`/forgot-password`
- 需要：手机号 + 短信验证码（`reset_password` 场景）+ 新密码

### 1.4 个人资料

- 路径：**我的** → **个人资料** / **设置**
- 可修改昵称、头像等（`GET/PATCH /api/customers/auth/profile/`）

## 2. 商品浏览

| 功能 | 入口 | 说明 |
|:---|:---|:---|
| 首页推荐 | `/` | 频道 Tab：推荐、秒杀、补贴等 |
| 分类 | 底栏 **分类** | 按类目浏览 |
| 搜索 | 顶部搜索框 | 关键词搜索 |
| 商品详情 | 点击商品 | 价格、库存、评价、促销标签 |
| 店铺主页 | 商品/店铺入口 | 查看单店商品与评分 |

---

## 3. 购物车

| 操作 | 说明 |
|:---|:---|
| 加入购物车 | 详情页选择数量后添加 |
| 未登录 | 购物车保存在浏览器本地，登录后自动合并到账号 |
| 修改数量 | 购物车页增减数量 |
| 勾选结算 | 仅结算已勾选商品 |
| 删除 | 左滑或删除按钮移除单品 |

API：`GET /api/cart/my_cart/` 等，见 [接口文档](../02-开发人员专用/接口文档.md#cart购物车)。

---

## 4. 下单与支付

1. 购物车 → **去结算**
2. 选择 **收货地址**（`/profile/addresses` 管理）
3. 可选：**优惠券**、**积分抵扣**、**国补资格**（若商品参与）
4. 提交订单 → 待付款
5. 演示环境：**模拟支付** 或按页面指引完成付款

---

## 5. 订单管理

路径：**我的订单** `/orders`

| 状态 | 用户可做什么 |
|:---|:---|
| 待付款 | 支付或取消 |
| 待发货 | 申请取消（需商家/平台审核时按提示操作） |
| 待收货 | 查看物流、确认收货 |
| 已完成 | 评价、申请售后 |
| 已取消 | 查看取消原因 |

订单详情页可查看物流轨迹（对接物流查询 API）。

## 9. 常见问题

**Q：为什么购物车登录前后数量变了？**  
A：登录后会合并浏览器里的临时购物车与账号购物车，以服务端为准。

**Q：积分为什么没到账？**  
A：确认积分规则是否启用；签到每日仅一次。

**Q：如何联系商家？**  
A：从店铺页或订单详情进入客服会话。

**Q：忘记密码怎么办？**  
A：使用「找回密码」通过短信重置。
