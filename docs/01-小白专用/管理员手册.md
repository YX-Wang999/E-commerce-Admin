# 管理员手册

> 面向：平台运营人员（`admin/`）与商家（`seller/`）  
> 演示密码：**admin123456**（`python manage.py init_data` 后可用）

---

## 一、平台管理后台（admin）

开发访问：**[http://localhost:5173](http://localhost:5173)**
非开发访问：**[https://admin.wangyixiang.xyz](https://admin.wangyixiang.xyz)**


### 1.1 登录


| 账号                          | 角色    | 典型权限     |
| --------------------------- | ----- | -------- |
| `admin`                     | 超级管理员 | 全部菜单     |
| `ops_director`              | 运营总监  | 商品、促销、报表 |
| `ops_manager` / `ops_staff` | 运营    | 日常运营     |
| `cs_staff`                  | 客服    | 客服工作台、投诉 |
| `warehouse`                 | 仓库    | 发货、库存    |
| `data_analyst`              | 数据分析  | 报表只读     |


- 中高风险登录会触发 **滑块验证码**
- 首次登录可能强制 **修改密码**（业务码 `1001`）

### 1.2 核心菜单与操作


| 模块        | 典型操作                     |
| --------- | ------------------------ |
| **仪表盘**   | 销售概览、待办事项                |
| **商品管理**  | 类目/品牌/商品 CRUD、上下架、库存日志   |
| **订单管理**  | 订单列表、发货、导出、售后/退款审核       |
| **促销管理**  | 秒杀、拼团、优惠券、超级折扣（含审核流）     |
| **会员管理**  | 商城用户列表、禁用、会员等级           |
| **商户管理**  | 入驻审核、暂停/恢复、变更审核、申诉       |
| **客服工作台** | 客户会话、商户会话、投诉处理           |
| **审核工作台** | 统一待审单（店铺注销、标签参与等）        |
| **国补管理**  | 政策、备案、订单上报               |
| **标签系统**  | 平台标签、商家参与审核、商品标签（最多 3 个） |
| **数据报表**  | 销售、商品排行、客户分析、财务汇总        |
| **系统设置**  | 系统参数、角色显示名、公告            |
| **权限管理**  | 用户、角色、菜单、部门、操作日志         |




### 1.3 通知与红点

- 顶部 **铃铛**：未读通知列表
- **审核工作台** 图标：待审数量
- **客服** 图标：未读会话数
- WebSocket 实时推送 + 断线 30 秒轮询兜底
- 新消息时浏览器标题显示 `(数量)` 或短暂 `【新消息】`



### 1.4 常见操作流程

**商品上架**

1. 商品管理 → 新建商品 → 填写类目、价格、库存、图片
2. 保存后点击 **上架**（`POST .../on_sale/`）

**订单发货**

1. 订单管理 → 筛选「待发货」
2. 进入详情 → 填写快递公司与单号 → 发货

**商户入驻审核**

1. 商户列表 → 待审核申请
2. 查看资料 → 通过或驳回

**售后退款**

1. 售后列表 → 待处理
2. 审核通过/驳回并填写备注

## 二、商家后台（seller）

开发访问：**[http://localhost:5175](http://localhost:5175)** 
非开发访问：**[https://seller.wangyixiang.xyz/](https://seller.wangyixiang.xyz/)** 
### 2.1 登录

- 使用商家员工账号（与平台 `User` 关联，通过 `TenantStaff` 绑定店铺）
- 演示：`13900000001` / `admin123456`（需 `init_data` 种子）



### 2.2 核心功能


| 模块         | 操作                  |
| ---------- | ------------------- |
| **工作台**    | 今日订单、待发货、待处理售后概览    |
| **商品**     | 本店商品列表、上下架（权限范围内）   |
| **订单**     | 查看、发货、取消审核、售后       |
| **促销**     | 本店秒杀/拼团/优惠券（提交平台审核） |
| **客服**     | 与客户在线沟通             |
| **店铺设置**   | 店铺资料、员工管理、积分规则      |
| **申诉/站内信** | 平台处罚申诉、回复通知         |
| **标签**     | 参与平台标签活动、配置商品促销标签   |




### 2.3 新订单提醒

- 通知铃铛 + WebSocket 推送
- 新订单/待发货类通知可弹窗 + 标题 `【新消息】` 提示

## 三、三端协作关系

```
买家 (customer) ──下单──▶ 商家 (seller) 发货
        │                      │
        └────── 平台 (admin) 监管、客服、审核、报表
```

- **Customer**（买家）与 **User**（员工）数据分离，共用 `adminAPI` 后端
- 商家数据按 **Tenant（店铺）** 隔离

---



## 四、常见问题


| 问题       | 处理                                      |
| -------- | --------------------------------------- |
| 登录后菜单为空  | 检查角色权限；执行 `python manage.py sync_menus` |
| 看不到审核工作台 | 需相应 RBAC 菜单权限                           |
| 商家看不到订单  | 确认 `tenant_code` 与登录店铺一致                |
| 图片上传失败   | 检查 `MEDIA` 目录权限与 `/api/upload/image/`   |
