# 快速开始（5 分钟上手）

> 面向：第一次使用商城的买家  
> 前置：本地或演示环境已启动（见 [环境搭建](../02-开发人员专用/环境搭建.md)）

---

## 你将完成什么

注册账号 → 登录 → 浏览商品 → 加入购物车 → 下单 → 查看订单。

---

## 第一步：打开商城

浏览器访问：**[http://localhost:5174](http://localhost:5174)**（本地开发默认地址）  
浏览器访问：**[https://customer.wangyixiang.xyz](https://customer.wangyixiang.xyz)**（非开发默认地址）

---

## 第二步：注册账号

1. 点击右上角 **「免费注册」** 或底部导航 **「我的」** → 登录页 → **注册**
2. 填写：
  - **手机号**（支持国际号码格式）
  - **短信验证码**（开发环境未接阿里云时，接口会返回 `dev_code` 供测试）
  - **登录密码**
3. 提交后自动登录

> 已有账号？直接 **登录**：支持手机号、昵称或邮箱 + 密码。

**演示账号**（需先执行 `python manage.py init_data`）：

- 手机号：`13800000000`
- 密码：`admin123456`

---



## 第三步：浏览并搜索商品

1. 首页向下滚动，查看推荐、秒杀、补贴等频道
2. 顶部搜索框输入关键词（如「手机」）回车
3. 点击商品卡片进入 **商品详情**

---



## 第四步：加入购物车

1. 在详情页选择数量
2. 点击 **「加入购物车」**
3. 底部导航 **「购物车」** 可查看已选商品
4. 勾选要结算的商品

---



## 第五步：下单

1. 购物车点击 **「去结算」**
2. 若无收货地址，先 **新增地址**（姓名、手机、省市区、详细地址）
3. 确认商品、地址、金额
4. 提交订单

> 演示环境可使用 **模拟支付** 完成付款（订单状态变为「待发货」）。

---



## 第六步：查看订单

1. 顶部 **个人中心** → **我的订单**，或底部 **「我的」** → 订单入口
2. 可查看：待付款、待发货、待收货、已完成
3. 点击订单号查看物流与详情

---



## 常见问题


| 问题      | 处理                                  |
| ------- | ----------------------------------- |
| 打不开页面   | 确认 `customer` 前端与 `adminAPI` 后端均已启动 |
| 登录失败    | 检查账号密码；演示账号需先 `init_data`           |
| 收不到短信   | 开发环境查看注册接口返回的 `dev_code`            |
| 购物车数量不对 | 刷新页面；登录后会自动合并本地购物车                  |
