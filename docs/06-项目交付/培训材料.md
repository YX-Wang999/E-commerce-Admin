# 培训材料（PPT 大纲）

> 面向：客户方运营、商家、内部培训  
> 建议时长：每场 1～1.5 小时

---

## 场次一：商城买家培训（30 分钟）

**对象**：终端用户、客服兼职  
**文档**：[快速开始](../01-小白专用/快速开始.md)、[用户手册](../01-小白专用/用户手册.md)

| 页 | 主题 | 要点 |
|:---:|:---|:---|
| 1 | 封面 | 商城名称、培训日期 |
| 2 | 如何注册登录 | 手机号、验证码、演示账号 |
| 3 | 找商品 | 搜索、分类、频道 |
| 4 | 购物车与下单 | 加购、地址、支付 |
| 5 | 查订单与物流 | 状态说明 |
| 6 | 积分与优惠券 | 签到、领券入口 |
| 7 | 联系客服 | 在线 chat、消息中心 |
| 8 | Q&A | 常见问题 |

**演示环境**：http://localhost:5174

## 场次二：商家培训（45 分钟）

**对象**：店铺管理员、运营、仓管  
**文档**：[管理员手册](../01-小白专用/管理员手册.md) §二

| 页 | 主题 | 要点 |
|:---:|:---|:---|
| 1 | 商家后台概览 | 登录、工作台 |
| 2 | 订单处理 | 待发货、发货、取消审核 |
| 3 | 商品管理 | 上下架、库存注意 |
| 4 | 促销活动 | 秒杀/拼团/券提交审核 |
| 5 | 客服与售后 | 回复买家、退款处理 |
| 6 | 店铺积分与标签 | 规则配置、标签最多 3 个 |
| 7 | 申诉与通知 | 铃铛、新订单提醒 |
| 8 | Q&A | |

**演示环境**：http://localhost:5175
