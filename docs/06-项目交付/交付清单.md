## 4. 环境依赖

| 类型 | 要求 |
|:---|:---|
| Node.js | ^22.14 或 >=24 |
| Python | 3.10+ |
| 数据库 | SQLite（开发）/ MySQL（生产推荐） |
| Redis | Channels 生产推荐 |
| 反向代理 | Nginx + HTTPS |

---

## 5. 初始化命令

```bash
cd adminAPI
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py init_data
python manage.py sync_menus
```
