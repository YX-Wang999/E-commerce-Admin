## 子项目与端口（开发环境）

| 子项目 | 路径 | 端口 | 说明 |
|:---|:---|:---:|:---|
| 平台后台 | `admin/` | 5173 | Vue 3 + Element Plus |
| 商城前台 | `customer/` | 5174 | Vue 3 + Vant |
| 商家后台 | `seller/` | 5175 | Vue 3 + Element Plus |
| 统一 API | `adminAPI/` | 8000 | Django + DRF + Channels（Daphne） |

## 演示账号（密码均为 `admin123456`）

| 端 | 账号示例 | 说明 |
|:---|:---|:---|
| 平台后台 | `admin` | 超级管理员 |
| 平台后台 | `ops_staff`、`cs_staff`、`warehouse` 等 | 见 `init_data` 输出 |
| 商家端 | `13900000001` | 商家员工（需先 `init_data`） |
| 商城 | `13800000000` ~ `13800000004` | 演示客户 |

初始化命令：`cd adminAPI && python manage.py init_data`

## 文档维护约定

1. **以代码为准**：接口、表结构变更后同步更新 `02-开发人员专用/` 对应文档。
2. **面向受众写**：小白文档不写 HTTP 状态码；开发文档不写「点击按钮」式废话。
3. **交叉引用**：各文档通过相对链接互链，避免重复大段内容。
