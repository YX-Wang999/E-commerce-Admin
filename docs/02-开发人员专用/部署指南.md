# 部署指南（开发视角）

> 面向：后端开发 / 需了解上线的全栈  
> 运维详细步骤见 [部署手册](../03-运维人员专用/部署手册.md) 与 [deploy/README.md](../../deploy/README.md)

---

## 1. 生产架构

```
浏览器 ──HTTPS──▶ Cloudflare / Nginx
                      ├── 静态文件 (adminDist / sellerDist / customerDist)
                      └── 反代 /api、/media、/ws ──▶ Daphne (systemd)
```

- **禁止** 生产使用 `runserver`
- WebSocket 必须与 HTTP 同域反代（`/ws`）
- `SECURE_PROXY_SSL_HEADER` 依赖 Nginx 转发 `X-Forwarded-Proto`

---

## 2. 构建产物

### 2.1 前端（本地构建）

```powershell
# Windows
copy deploy\env\frontend-build.env.example deploy\env\frontend-build.env
# 填入生产 https 域名
powershell -ExecutionPolicy Bypass -File deploy\scripts\build-release.ps1
```

产物：`deploy/release/*.tar.gz`（三端静态 + backend）

### 2.2 后端

- 打包 `adminAPI/` 至服务器 `backend/`
- 虚拟环境 + `pip install -r requirements.txt`
- `.env` 生产配置（数据库、SECRET_KEY、CORS、短信等）

---

## 3. 服务器目录（约定）

```
/var/www/admin/
├── adminDist/
├── sellerDist/
├── customerDist/
├── backend/        # Django + venv
└── deploy/         # 脚本
```

---

## 4. 后端 systemd 示例

服务名示例：`ecommerce-backend`

```ini
[Unit]
Description=E-commerce Daphne ASGI
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/admin/backend
EnvironmentFile=/var/www/admin/backend/.env
ExecStart=/var/www/admin/backend/venv/bin/daphne -b 127.0.0.1 -p 8002 config.asgi:application
Restart=always

[Install]
WantedBy=multi-user.target
```

部署后：

```bash
python manage.py migrate
python manage.py sync_menus
systemctl restart ecommerce-backend
```

---

## 5. Nginx 要点

- 三域名分别指向三份静态目录（见 `deploy/nginx/08|09|10-*.conf`）
- `location /api/` 与 `location /ws/` 反代到 Daphne
- `client_max_body_size` 适配图片上传
- 静态资源长期缓存；`index.html` 不缓存

## 6. 环境变量（生产必查）

| 变量 | 说明 |
|:---|:---|
| `DEBUG=False` | 关闭调试 |
| `SECRET_KEY` | 随机强密钥 |
| `ALLOWED_HOSTS` | 公网域名 |
| `CORS_ALLOWED_ORIGINS` | 三端 https 源 |
| `DATABASE_URL` / MySQL 配置 | 生产库 |
| `CHANNEL_LAYERS` | Redis 地址 |
| `ALIYUN_SMS_*` | 短信（若启用） |

参考：`deploy/env/backend.env.example`

## 8. 常见问题

### `Unsupported protocol D:`（axios）

浏览器控制台出现该错误，说明 **`VITE_API_BASE_URL` 被误设成 Windows 盘符路径**（如 `D:\项目\...`），axios 会把 `D:` 当成 URL 协议。

**处理：**

1. 检查系统/用户环境变量，删除错误的 `VITE_API_BASE_URL`、`VITE_API_ORIGIN`
2. 各端 `.env` 应使用相对路径：`VITE_API_BASE_URL=/api`
3. 本地开发重启 `npm run dev`；生产需重新 `build-release` 并部署 dist

项目已在 `shared/utils/apiBase.js` 中自动忽略盘符路径并回退为 `/api`。
