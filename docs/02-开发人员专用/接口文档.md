# 接口文档

> 面向：前后端开发、测试  
> 路由源码：`adminAPI/config/urls.py` 及各 app `urls.py`  
> 在线调试：开发环境 `http://localhost:8000` + 对应端 Token

---

## 1. 通用约定

### 1.1 Base URL

| 环境 | 地址 |
|:---|:---|
| 本地 | `http://localhost:8000` |
| 生产 | `https://<域名>/api/...`（Nginx 反代） |

### 1.2 响应格式

**成功**

```json
{
  "code": 0,
  "data": { },
  "message": "success"
}
```

**失败**

```json
{
  "code": 40007,
  "data": null,
  "message": "错误说明"
}
```

### 1.3 认证 Header

| 身份 | Header |
|:---|:---|
| 后台员工 | `Authorization: Bearer <access_token>` |
| 商城用户 | `Authorization: Bearer <customer_access_token>` |
| 商家 WS | URL 参数 `token` + `tenant_code` |

### 1.4 常用业务码

| code | 含义 |
|:---:|:---|
| 0 | 成功 |
| 1001 | 后台首次登录须改密 |
| 40002 | 商城账号或密码错误 |
| 40100 | Token 无效 |
| 40300 | 无权限 |
| 50000 | 服务器错误 |

### 1.5 WebSocket

| 路径 | 说明 |
|:---|:---|
| `ws://host/ws/notify/?token=` | 全局通知（三端） |
| `ws://host/ws/chat/{id}/?token=` | 客服会话 |

推送 payload 示例：

```json
{
  "type": "notification",
  "notification_id": 1,
  "title": "待发货 #ORD001",
  "notification_type": "order_paid",
  "need_popup": true,
  "need_sound": true,
  "related_url": "/orders"
}
```

```json
{ "type": "cart_update", "count": 3 }
```

## 2. 认证与账号

### 2.1 后台员工 `/api/auth/`

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| POST | `/api/auth/login/` | 登录 |
| POST | `/api/auth/refresh/` | 刷新 Token |
| GET | `/api/auth/profile/` | 资料 + 菜单 |
| POST | `/api/auth/change-password/` | 改密 |
| POST | `/api/auth/forgot-password/` | 邮箱找回 |
| GET | `/api/auth/captcha/` | 滑块拼图 |
| POST | `/api/auth/captcha/verify/` | 验证滑块 |
| GET | `/api/auth/captcha/trust/` | 信任等级 |

### 2.2 商城用户 `/api/customers/auth/`

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| POST | `/api/customers/auth/send-sms/` | 发短信 `{ phone, scene }` |
| POST | `/api/customers/auth/register/` | 注册 |
| POST | `/api/customers/auth/login/` | 登录 `{ account, password }` |
| POST | `/api/customers/auth/refresh/` | 刷新 |
| POST | `/api/customers/auth/reset-password/` | 重置密码 |
| GET/PATCH | `/api/customers/auth/profile/` | 个人资料 |

别名：`POST /api/send-sms/`

### 2.3 商家 `/api/seller/auth/`

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| POST | `/api/seller/auth/login/` | 商家登录 |
| GET | `/api/seller/auth/profile/` | 商家资料 |

## 14. 分页与筛选

列表接口通常支持：

```
?page=1&page_size=20&search=关键词&status=xxx
```

具体字段见各 ViewSet `filterset_fields` / `get_queryset`。
