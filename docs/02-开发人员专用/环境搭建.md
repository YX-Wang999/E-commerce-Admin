# 环境搭建

> 面向：新入职开发人员  
> 预计耗时：30～60 分钟（含依赖下载）

---

## 1. 环境要求

| 工具 | 版本建议 |
|:---|:---|
| Node.js | ^22.14 或 >=24（见各端 `package.json` engines） |
| Python | 3.10+ |
| Git | 任意近期版本 |
| Redis | 可选；Channels 生产环境推荐 |

## 3. 后端（adminAPI）

```powershell
cd adminAPI
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

编辑 `.env` 关键项（开发可留默认）：

```env
DEBUG=True
SECRET_KEY=your-secret-key
# 短信开发模式
ALIYUN_SMS_ENABLED=False
```

初始化数据库与演示数据：

```powershell
python manage.py migrate
python manage.py init_data
python manage.py sync_menus
```

启动（**必须 Daphne**，否则 WebSocket 不可用）：

```powershell
.\run-dev.bat
# 或: daphne -b 0.0.0.0 -p 8000 config.asgi:application
```

验证：浏览器或 curl 访问 `http://localhost:8000/api/system/settings/public/`（需员工 Token）。

## 9. 常见问题

| 现象 | 处理 |
|:---|:---|
| 前端 API 404 | 确认后端 8000 已启动；检查 Vite 代理 |
| WebSocket 连不上 | 必须用 Daphne，不要用纯 `runserver`（无 WS） |
| 菜单为空 | `python manage.py sync_menus` |
| 短信验证码 | `ALIYUN_SMS_ENABLED=False` 时响应含 `dev_code` |
| migrate 报错 | 检查 Python 版本与依赖；删除 test DB 重试 |
| CORS 错误 | `.env` 中 `CORS_ALLOWED_ORIGINS` 包含 5173/5174/5175 |
