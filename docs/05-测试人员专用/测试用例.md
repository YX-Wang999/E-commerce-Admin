# 测试用例

> 面向：测试工程师  
> 自动化源码：`adminAPI/*/tests.py`、`customer/src/__tests__/`、`e2e/`  
> 详细清单同步：[adminAPI/TEST_CASES.md](../../adminAPI/TEST_CASES.md)

---

## 1. 测试策略

| 层级 | 目标 | 工具 |
|:---|:---:|:---|
| 后端 API | 核心逻辑 80% | Django TestCase |
| 前端组件 | 关键页 60% | Vitest |
| E2E 主路径 | 100% | Playwright |
| 手工探索 | 新功能/regression | 本表 |

## 3. 商城功能测试

| ID | 模块 | 场景 | 步骤 | 预期 |
|:---|:---|:---|:---|:---|
| C-01 | 注册 | 正常注册 | 手机号+验证码+密码 | 注册成功并登录 |
| C-02 | 注册 | 验证码错误 | 错误 code | 提示失败 |
| C-03 | 登录 | 密码错误 | 错误密码 | code=40002 |
| C-04 | 商品 | 浏览列表 | 打开首页 | 展示上架商品 |
| C-05 | 商品 | 详情 | 点击商品 | 价格库存正确 |
| C-06 | 购物车 | 加购 | 详情页加购 | 购物车数量+1 |
| C-07 | 购物车 | 未登录 | 加购后登录 | 合并购物车 |
| C-08 | 下单 | 正常下单 | 选地址结算 | 订单 pending |
| C-09 | 下单 | 无地址 | 直接结算 | 引导新增地址 |
| C-10 | 订单 | 模拟支付 | mock-pay | 状态变 paid |
| C-11 | 订单 | 取消待付款 | 取消 | cancelled |
| C-12 | 积分 | 签到 | 积分中心签到 | 积分增加 |
| C-13 | 积分 | 重复签到 | 当日再签 | 提示已签到 |
| C-14 | 通知 | 未读数 | 发货后 | 铃铛/标题有未读 |
| C-15 | 客服 | 发消息 | 打开 chat 发送 | 消息可见 |

## 6. API 自动化（节选）

| 模块 | 场景 | 预期 |
|:---|:---|:---|
| 认证 | POST `/api/auth/login/` 正确密码 | code=0 + token |
| 商品 | GET `/api/products/` | 不含下架 |
| 订单 | 库存不足下单 | 失败提示 |
| 订单 | 客户 A 不能看 B 订单 | 仅本人 |
| 积分 | POST sign-in | 积分+ |

运行：

```bash
cd adminAPI && python manage.py test accounts.tests products.tests orders.tests points.tests
cd customer && npm run test
npx playwright test
```
